# 版本紀錄

## 1.2 · Google Play 版本

- 移除私人版的非 Play 素材，改用可再散布的免費表情貼圖。
- 改用 Twemoji v14.0.3 的 31 張 CC BY 4.0 表情圖像，並加入授權檔與來源說明。
- 目標 API 更新至 Android 16 / API 36，版本編號更新為 3。

## 1.1 · 2026-09-20

- 名稱改為「小小筆記」，沿用原套件 ID，可覆蓋更新並保留筆記。
- 文字顏色、彩虹與柔光工具列移至內文下方、貼圖／桌面預覽上方。
- 可在內容插入圖片，滑桿或雙指調整大小；點圖片可再次調整。
- 私人版素材包補齊全部 31 張靜態貼圖。
- 插入勾選方框，筆記和桌面小工具皆可點選，完成顯示綠色勾勾。
- 桌面勾選會持久保存；編輯器儲存會保留編輯期間的桌面勾選更新。
- 加入 GitHub 建置檢查與持續更新說明。

## 1.0 · 2026-09-19

多篇筆記、獨立選篇與可捲動的桌面小工具、文字顏色／彩虹／柔光、貼圖、背景圖片與淡化。
