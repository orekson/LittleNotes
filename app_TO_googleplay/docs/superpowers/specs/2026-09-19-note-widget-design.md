# Android 筆記與桌面小工具：第一版設計

狀態：使用者已確認開始撰寫；以下個人化增補依 2026-09-19 最新指示執行。

## 已授權的個人化增補（優先於下方原版純文字限制）

- 內文可在游標位置插入免費表情貼圖，並可從手機匯入自己的透明圖片。內建素材附來源與授權說明。
- 可選取文字套用顏色、彩虹漸層及柔光；沒有選取時套用整篇。效果可清除，儲存與重開後保留。
- 炫彩發光以靜態漸層及光暈呈現，並非持續閃動動畫。
- 可選內建背景或手機圖片，調整 0–100% 淡化；100% 代表照片完全淡至底色，文字與貼圖不受影響。
- 背景與文字樣式隨筆記儲存，所有選用同篇的小工具同步；不同篇可有不同外觀。
- 編輯器與預覽呈現富文字；桌面小工具將排版後內容分成小張圖片列，讓光暈及貼圖在 RemoteViews 限制下仍能一致顯示並上下捲動。
- 圖片匯入時縮小並複製至 App 私有目錄，不依賴外部相簿 URI 長期有效。原始相簿檔案不修改。
- 個人化增補納入同一版交付與測試。原文「純文字」與「主題編輯器不列入」僅對未指定的富文字功能／完整主題系統有效。

## 目的與已確認需求

使用者希望在 Android 上建立多篇筆記，並選擇其中一篇直接顯示於桌面小工具。
小工具可調整成接近參考圖片黑框的大面積，盡量讓筆記內容直接可見。
使用者已確認：內容過長時，維持易讀字體，於小工具內上下捲動。
圖片只作為尺寸參考，不將其中的文字或圖示視為功能需求。

## 建議的第一版範圍

- 繁體中文介面，支援 Android 8.0 以上；實機相容性仍需驗證。
- 純文字筆記，包含標題與內文；可新增、編輯及刪除。
- 筆記儲存於手機本機，不需帳號與網路。
- 每個桌面小工具各自選擇一篇筆記，可在放置後更換。
- 支援水平與垂直調整小工具尺寸；預設以較大的 4 × 4 格提出尺寸要求。
- 短筆記直接完整顯示；長筆記上下捲動，保留原本的換行與段落。
- 儲存筆記後，更新所有顯示該篇筆記的小工具。
- 小工具提供「編輯」與「換筆記」入口。

上述 Android 最低版本、純文字範圍、外觀與本機儲存方式為建議假設，尚非使用者指定。

## 技術方案比較

1. **建議：Kotlin 原生 Android App ＋ RemoteViews 桌面小工具。** 直接使用 Android 的小工具能力，能控制選文、尺寸與垂直捲動，適合這個小型專案。
2. **Kotlin ＋ Jetpack Glance。** 可使用 Compose 風格撰寫小工具，但仍受桌面小工具支援範圍限制；此版本不需要額外的 UI 抽象。
3. **Flutter 加原生小工具橋接。** 若未來需要多平台 App 可考慮，但目前只有 Android，額外橋接增加維護工作。

## 畫面與操作

### 筆記清單

顯示標題、內文摘要與最近修改時間，依最近修改排序。右下方提供新增按鈕。
沒有筆記時顯示「建立第一篇筆記」入口。清單也提供簡短的桌面小工具加入說明。

### 編輯筆記

標題與多行內文輸入欄位，提供明確的儲存按鈕。
空標題顯示為「未命名筆記」，有內文即可儲存；全空的新筆記不建立資料。
有未儲存修改時離開，提供儲存、捨棄與繼續編輯選項。
刪除需確認；儲存失敗時保留輸入內容並提示重試。

### 小工具設定

由桌面加入小工具時開啟選文畫面。選擇筆記後完成設定並立即顯示內容。
若沒有筆記，可建立一篇，儲存後回到選文流程。
取消首次設定時不留下無效的設定紀錄；取消更換時維持原選擇。

### 桌面小工具

預設為淺米白底、深色文字、圓角與小幅內距，以閱讀為優先。
上方以緊湊區域顯示標題及操作入口，其餘空間用於內文。
內文預設約 16sp，尊重系統字體比例，不因文章長度自動縮小。
小工具以可垂直捲動的文字集合實作，長段落分段承載，避免單一項目過高造成後半段難以捲入畫面。
分段不得遺漏、重複文字或破壞 Unicode 字元；保留原始筆記內容，不把呈現用分段寫回資料庫。
換文或儲存更新後允許回到文章頂端，第一版不保證記住捲動位置。

## 尺寸限制

參考圖片中的黑框接近全頁桌面。小工具會盡量填滿使用者分配的矩形空間。
實際格數、最大範圍與留白由桌面程式決定，無法保證跨手機得到完全相同的尺寸，
也無法覆蓋桌面程式保留的狀態列、底部快捷列或導覽區。
使用者可在空白桌面頁加入小工具，再長按拉大到桌面允許的尺寸。

## 元件、資料與更新

- 筆記儲存層：以本機 SQLite 儲存穩定 ID、標題、內文、建立時間及修改時間。
- 小工具設定層：儲存小工具 ID 與筆記 ID 對應，與筆記內容分開管理。
- App 畫面：筆記清單、編輯及小工具選文流程。
- 小工具提供者與集合資料來源：讀取指定筆記、呈現內容、接收尺寸與生命週期事件。
- 儲存成功後才通知相關小工具重新讀取內容，不依賴定時背景輪詢。
- 移除小工具只移除對應設定，不刪除筆記。
- 筆記被刪除時，相關小工具改顯示「筆記已刪除，請重新選擇」，不顯示舊內容。
- 程序被系統終止後仍可從持久資料重建內容；重新開機後由桌面及小工具生命週期恢復顯示。

## 驗收與驗證

1. 建立兩篇中文筆記，可獨立編輯且重啟 App 後仍存在。
2. 放置兩個小工具並各選不同筆記，不互相影響。
3. 編輯其中一篇並儲存，所有綁定該篇的實際桌面小工具更新，其他筆記維持原內容。
4. 在大、小尺寸下檢查換行、標題、操作入口與捲動區域，確認內容不橫向溢出。
5. 使用多段文章、單一超長段落、空白行、中文及 emoji，確認可以捲到最末文字，無遺漏或重複。
6. 取消選文、刪除被引用的筆記、移除小工具及重新加入時，顯示與資料符合上述行為。
7. 驗證未儲存離開處理與儲存錯誤處理，避免無提示丟失輸入。
8. 執行建置與適當的資料／文字分段測試；桌面操作另需模擬器或實機驗證。

交付目標為可開啟的 Android 專案原始碼、使用說明及 debug APK。
若環境缺少 Android SDK、JDK、依賴下載能力或裝置，明確列出未能執行的驗證，不以程式檢查取代實機結果。
